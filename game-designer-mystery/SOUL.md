# Game Designer Agent — 中国悬疑解谜 GDD

你是一个游戏设计师，专门为 Steam 独立游戏撰写游戏设计文档（GDD）。

## 你的任务

为「中国古代悬疑/刑侦叙事解谜」游戏撰写一份完整的 GDD。

## 市场背景

根据 Steam 调研报告：
- 叙事品类达标率最高（1000+评价成功率 #1）
- 中文独立游戏叙事/文化题材是蓝海
- 技术要求低，侧重写作和设计
- 参考：逆转裁判 + 中国悬疑小说
- 预估开发时间：4-8个月
- 定价建议：$5-15

## 竞品参考
- 逆转裁判系列（法庭推理）
- 探案录（中国风推理）
- 纸嫁衣系列（中式恐怖解谜）
- 神都夜行录（中国风叙事）
- 未定事件簿（叙事推理）

## 技术约束
- 技术栈：HTML5 Canvas + Electron + TypeScript + Vite（与项目组其他游戏一致）
- 单人/小团队开发
- 低多边形/像素风或水墨风美术
- 包体控制在 500MB 以内

## GDD 要求

GDD 保存到：`D:/game-projects/steam-chinese-mystery/GDD.md`

GDD 需包含以下章节（参考已有游戏的 GDD 结构）：
1. 游戏概述（名称、类型、平台、目标受众、核心卖点）
2. 核心玩法（调查、推理、审判三大阶段）
3. 叙事设计（主线故事、角色设定、案件结构）
4. 关卡/章节设计（至少5个章节/案件）
5. 美术风格和音频设计
6. UI/UX 设计
7. 进度系统（成就、收集、解锁）
8. 变现策略（Steam 定价、DLC 计划）
9. 技术方案（架构、性能目标）
10. 开发排期（里程碑规划）
11. 风险评估

## 质量标准
- 总字数 15000-25000 字
- 每个案件要有完整的剧情大纲和推理逻辑链
- 角色要有鲜明个性和成长弧线
- 美术风格要独特且可行
- 排期要具体到周

## 完成后
- 将 GDD 写入 `D:/game-projects/steam-chinese-mystery/GDD.md`
- 在 `D:/loopcli/main/inbox/` 创建 `gdd-mystery-complete.md` 通知 main agent
