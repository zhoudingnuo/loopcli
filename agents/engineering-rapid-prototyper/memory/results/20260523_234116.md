# M2 调查系统开发完成

## 任务
长安诡案录M2：调查系统

## 交付物
4个新模块 + 集成：

### 1. SceneExplorer.ts
- 点击式场景探索
- 热点检测（Hotspot）与高亮脉冲动画
- 可交互物品的分类：examine/pickup/talk/enter
- 条件锁（需要特定物证/flag才能互动）
- 摄像头平移/缩放（panTo/zoomTo）
- 详情面板渲染

### 2. EvidenceCollector.ts
- 物证收集（collect方法）
- 物证背包UI（右侧面板）
- 物证分类：关键(key)/普通(normal)/误导(misleading)
- 物证详情查看
- 收集闪光通知动画
- 滚动列表

### 3. InterrogationSystem.ts
- NPC注册与审问对话树
- 压力值系统（影响可问话题）
- 基于物证解锁对话选项
- 出示物证功能
- 话题条件系统（需要物证/flag/压力范围）
- 压力条UI渲染

### 4. EvidenceCombiner.ts
- 拖拽式物证组合
- 组合配方系统（CombinationRecipe）
- 逻辑验证（只有匹配配方的组合才产生新物证）
- 新线索生成
- 组合成功/失败反馈动画

### 集成
- UIManager扩展：新增UIScreen类型（explore/interrogation/evidence/combine）
- M2工具栏：底部导航栏（探索/审问/物证/组合/返回）
- Demo数据：预注册物证、热点、NPC、审问话题、组合配方
- 版本号更新：0.1.0 → 0.2.0
