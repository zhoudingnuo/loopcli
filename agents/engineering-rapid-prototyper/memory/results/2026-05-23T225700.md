# M1 基础框架开发结果

## 任务
长安诡案录M1阶段基础框架开发

## 完成时间
2026-05-23

## 交付物清单

### 1. 项目搭建
- `package.json` — 项目配置（Electron + Vite + TypeScript）
- `tsconfig.json` / `tsconfig.main.json` — 双配置（渲染进程 + 主进程）
- `vite.config.ts` — 构建配置，路径别名
- `electron-builder.json` — Electron 打包配置
- `index.html` — 入口HTML
- Vite 构建验证通过：12 模块，21.57 kB 输出

### 2. Canvas 水墨渲染系统 (src/utils/ink.ts)
- `InkRenderer` 类：墨迹粒子系统
- `spawnBurst()` — 墨迹爆裂效果
- `renderTransition()` — 水墨晕染场景过渡（扩散→消退双阶段）
- `renderInkFilter()` — 水墨滤镜后处理（像素级灰度转换+墨色调色）
- 不规则边缘墨迹扩散算法

### 3. 场景管理系统 (src/game/SceneManager.ts)
- 9个预注册场景（县衙、西市、东市废墟、大明宫、大慈恩寺、平康坊、地下、判官殿）
- 场景切换 + 水墨过渡动画
- 分层渲染（背景层 + 前景层）
- 环境光效果（径向渐变）
- 灯光系统（位置、半径、强度可配）
- `update()` / `render()` 双循环

### 4. 对话引擎 (src/game/DialogueEngine.ts)
- JSON 驱动对话树
- 分支选择节点
- 打字机效果（可配速度）
- 角色立绘显示支持
- 条件系统（flag/evidence/choice 三类条件）
- 效果系统（设置标记、添加物证、设置选择、修改关系值）
- 内置演示对话（裴如意初见场景）

### 5. 基础UI (src/renderer/UI/UIManager.ts)
- 主菜单（水墨风标题、菜单项、hover效果、装饰性水墨晕染背景）
- 对话框UI（古卷轴样式、角色名牌、自动换行、选择按钮、闪烁提示符）
- 设置面板（文字速度、主音量、音乐音量、音效音量、滑块控件）
- 存档槽位界面（6格、hover高亮、空档显示）
- 返回按钮
- 输入管理器 (src/game/InputManager.ts) — 鼠标点击/移动/键盘事件

### 6. 其他系统
- GameState (src/game/GameState.ts) — 全局状态（章节、标记、物证、选择、NPC关系）
- SaveGame (src/game/SaveGame.ts) — localStorage 存档系统
- InputManager (src/game/InputManager.ts) — 输入管理
- Renderer (src/renderer/Renderer.ts) — 2D Canvas 渲染封装
- App (src/renderer/App.ts) — 游戏主循环（requestAnimationFrame，60FPS）

### 7. 数据文件
- `src/data/scenes.json` — 4个详细场景定义
- `src/data/characters.json` — 5个角色定义（含立绘列表）
- `src/data/evidence.json` — 物证定义

### 8. Electron 主进程
- `src/main/main.ts` — 窗口创建、开发/生产模式切换

## 技术亮点
- 纯 TypeScript，零运行时框架依赖（仅 howler.js 用于音频预留）
- 水墨风渲染：粒子系统 + 径向渐变 + 不规则边缘 + 像素级后处理
- 对话引擎支持条件分支、物证触发、关系值修改
- 完整的游戏循环：requestAnimationFrame + delta time
- Vite 构建通过，21.57 kB gzip 7.18 kB
