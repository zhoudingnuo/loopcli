## 已实现功能
- **完整三消机制**：8x8网格，6种棋子，交换匹配3+消除
- **触摸操作**：点选交换 + 滑动手势
- **重力系统**：消除后棋子下落，自动补充新棋子
- **连锁反应**：自动检测级联匹配（combo连击）
- **分数系统**：3消100分、4消250分、5消500分，连击倍率加成
- **关卡系统**：8级目标分数递增（3000→50000），每关30步
- **视觉效果**：粒子爆炸、分数弹出、连击文字、屏幕震动、棋子高光渐变
- **6种棋子造型**：圆形、菱形、方块、三角、星形、六边形
- **UI界面**：顶部状态栏（分数/关卡/进度条/剩余步数）、底部重启按钮
- **游戏流程**：开始 → 游戏 → 过关/游戏结束 → 再来/下一关
- **抖音小游戏适配**：tt API适配层，竖屏优化，触控事件
- **浏览器测试**：index.html可直接在浏览器中运行测试
- **数据持久化**：最高分和最高关卡本地存储

## 技术栈
- HTML5 Canvas 渲染
- CommonJS 模块系统（兼容抖音小游戏）
- 抖音 tt API + 浏览器降级适配
- requestAnimationFrame 游戏循环
- 补间动画系统（缓动函数）
