## Task #24: 修复三消游戏3个P0 Bug + 关卡平衡

### Bug 1: DailySystem任务双倍计数 (FIXED)
**文件**: `D:/game-projects/douyin-match3/src/js/DailySystem.js`
**原因**: `reportEvent()` 中 `clear_obstacle` 事件同时匹配了两个独立的 `if` 块，导致进度被累加两次。
**修复**: 将第二个 `if` 改为 `else if`，确保 clear_obstacle 只走一条路径。clear_obstacle 特殊路径（支持 subType 过滤）优先匹配，通用路径作为 fallback。

### Bug 2: Board.shuffle null崩溃 (FIXED)
**文件**: `D:/game-projects/douyin-match3/src/js/Board.js`
**原因**: `shuffle()` 遍历 grid 时直接访问 `this.grid[r][c].color`，但某些格子可能为 null（如 boss 占位格、障碍物清除后的空格）。
**修复**: 收集和回写颜色时跳过 null 格子，使用 `|| this._randomColor()` 兜底。

### Bug 3: ScoreSystem步数边界 (FIXED)
**文件**: `D:/game-projects/douyin-match3/src/js/ScoreSystem.js`
**原因**: `useMove()` 先执行 `this.moves++` 再检查剩余步数，当剩余步数已为 0 时仍会递增计数器，导致状态损坏。
**修复**: 先检查 `getRemainingMoves() <= 0`，只有步数充足时才递增。
