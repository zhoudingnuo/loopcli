# M6 叙事系统 — 完成报告

## 任务
深夜便利店 v0.5.0 → v0.6.0 M6 叙事里程碑

## 交付模块

### 1. NarrativeTypes.ts
共享类型定义：StoryLayer(6层), ClueType(6种), ClueCategory(6种), EndingType(5种结局), 以及 Clue, Ending, NarrativeChoice, RadioSegment, StoryNote 等接口。

### 2. ClueManager.ts — 75+ 线索系统
- 75条完整线索，按6层叙事分层（表层15 + 第一层15 + 第二层15 + 第三层15 + 第四层15 + 核心10）
- 6种线索来源：笔记、监控、异常商品、广播、顾客对话、环境叙事
- 前置条件链：关键线索需要先发现前置线索
- 自动发现机制：环境和监控类线索在新一天自动发现
- 存档/读档支持

### 3. StoryManager.ts — 6层洋葱叙事引擎
- 6层叙事结构：表层(Day1-5) → 第一层(Day6-10) → 第二层(Day11-15) → 第三层(Day16-20) → 第四层(Day21-25) → 核心(Day26-30)
- 层级自动解锁、进度追踪
- 故事事件系统、flag标记系统
- 与ClueManager联动

### 4. EndingSystem.ts — 5结局系统
- 结局A：逃离（还清债务+避免深入调查）
- 结局B：接管（深入调查+选择接受）
- 结局C：对抗（收集55+线索+选择对抗）
- 结局D：融合（高异常互动+进入平行店）
- 结局E：真相（收集65+线索+理解他+听到他的声音）
- 条件评估、强制触发(Day30)、进度提示

### 5. RadioManager.ts — 深夜广播系统
- 10段广播节目，随天数递进解锁
- 每段广播对应特定时间段和线索奖励
- 逐行播放机制，完成后授予线索
- 深夜时段限制（23:00-5:00）

### 6. NoteManager.ts — 笔记系统
- 22条可发现笔记（日记、研究笔记、警告、收据、照片）
- 位置绑定（仓库、收银台、休息室、地下室等）
- 阅读后授予关联线索
- 按层级组织

### 7. NarrativeChoiceManager.ts — 叙事选择系统
- 10个关键选择节点，贯穿30天剧情
- 每个选择影响结局走向（设置flag）
- 选择消耗理智值，可能奖励线索
- 选择历史记录和存档

### 8. App.ts集成
- 完整集成所有M6系统到游戏主循环
- 新增公共API：playRadio, readNote, searchLocation, makeNarrativeChoice等
- 新游戏状态字段：storyLayer, cluesFound, totalClues, choicesMade, endingType
- 每日自动发现线索、Day30强制结局触发
