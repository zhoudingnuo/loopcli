# 任务 #17 修复WebUI配额重复显示bug

## 问题描述
WebUI用量统计栏显示两个Token配额5h。原因：server.py中 `if "TOKEN" in t` 匹配了API返回的所有TOKEN类型条目，导致重复添加。

## 修复方案
在 server.py 第266行配额处理逻辑中添加 `seen_token` 去重标记，只取第一个TOKEN类型条目。

## 修改文件
- `D:/loopcli/main/webui/server.py` 第267行：添加 `seen_token = False` 初始化
- 第273行：条件改为 `if "TOKEN" in t and not seen_token:`，匹配后设置 `seen_token = True`

## 验证
- 修复后WebUI只显示一个Token配额条目
- TIME类型配额不受影响
