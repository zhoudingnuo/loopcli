## 交付模块

### 1. ProductManager.ts — 商品管理与供应商系统
- 5大商品类别：饮料(8种)、零食(10种)、便当(4种)、日用品(6种)、特殊商品(3种)
- 4种供应商：正规批发(Day1)、特价渠道(Day3)、匿名供货(Day7)、前任店员遗留(Day10)
- 库存管理：仓库容量、货架容量、过期检测、订货到货流程
- 货架系统：7个货架位(5个普通+2个冰柜)，上架/下架操作

### 2. Customer.ts + CustomerManager.ts — 顾客AI系统
- 5种顾客类型：上班族(早高峰)、白领(午休)、学生(下午)、居民(晚间)、深夜顾客(夜间)
- 行为链：进入→走向货架→浏览→取货→走向收银→排队→结账→离开
- 路径导航：基于路点的简单导航，支持7个货架区域
- 耐心系统：超时自动离开，影响满意度统计
- 学生偷窃概率(5%)

### 3. CashRegister.ts — 收银系统
- 完整收银流程：扫描→付款→找零→收据
- 税率6%
- 异常事件：深夜顾客/特殊商品触发30%概率异常（收银机自动打开、异常日期收据等）
- 双收银台支持

### 4. PricingSystem.ts — 动态定价
- 每个商品独立定价，价格范围50%-200%基准价
- 时段需求调制：早高峰饮料+30%、午休便当+40%、下午零食+20%、深夜特殊商品+100%
- 价格敏感度计算：影响顾客购买决策

### 5. EconomySystem.ts — 经济循环
- 30万债务，30天还清期限
- 日固定支出：房租¥100 + 电费¥20
- 8种店铺升级：摄像头/灯光/防盗门/收银机升级/仓库货架/紧急按钮/收音机/手电筒
- 每种升级关联恐怖元素
- 日结算报告系统
- 游戏结束判定：还清债务/破产/超时

### 6. ShelfInteraction.ts — 货架交互
- 面对货架按E键查看/管理
- 上架：从仓库选择商品放到指定货架
- 下架：从货架取回仓库
- 货架类型匹配（冰柜→饮料/便当，普通→零食/日用品）
