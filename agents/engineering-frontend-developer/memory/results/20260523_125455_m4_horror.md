## 交付物

### 1. HorrorEventManager.ts — 事件触发引擎
- 4个恐怖等级: Environment(微恐) / Entity(中恐) / Threat(高恐) / Existential(极高恐)
- **15种恐怖事件**:
  - Level 1 (5种): 商品位移, 收银机异常, 灯光闪烁, 温度骤降, 冰箱异响
  - Level 2 (4种): 透明顾客, 重复脸顾客, 影子错位, 诡异新商品
  - Level 3 (4种): 门自动开, 货架流血, 不付款顾客, 低语声
  - Level 4 (2种): 店铺异变, 时间异常
- 事件3阶段状态机: 预兆(Buildup) → 活跃(Active) → 消退(Resolving)
- 恐惧调节系统: 连续高恐事件后降级，低理智时减少触发
- 白天绝对安全，深夜密度递增
- 最多3个并发事件

### 2. AudioManager.ts — 音效系统
- Web Audio API 生成所有音效，无外部音频文件
- 恐怖音效: 电流闪烁, 低语, 门吱呀, 突然寂静, Jump Scare, 氛围Drone
- 3种BGM: 白天(柔和pad), 夜晚(诡异drone), 危险(drone+心跳)
- 音量控制: Master/BGM/SFX独立调节

### 3. 视觉特效 (Renderer.ts)
- 暗角/霜冻/额外黑暗/屏幕震动/色差/血迹/鬼魂实体/门开效果/时间故障/低语覆盖/恐惧指示器

### 4. 集成 (App.ts)
- HorrorEventManager + AudioManager 完整集成到游戏循环
- BGM随日夜阶段自动切换
- 恐怖事件触发音效
- 新一天重置恐怖状态
- Sanity值影响恐怖触发概率
