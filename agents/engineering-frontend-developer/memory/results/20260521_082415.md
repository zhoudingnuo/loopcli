# 任务 #7：修复安全审计发现的 High 问题

**完成时间**：2026-05-21 08:24:15
**执行者**：engineering-frontend-developer

## 修复内容

### HIGH-1: 请求体大小限制

**问题**：`_read_body()` 无大小限制，攻击者可发送超大请求体导致内存耗尽。

**修复**：
- 新增 `MAX_BODY_SIZE = 10 * 1024`（10KB）常量
- `_read_body()` 增加 `length > MAX_BODY_SIZE` 检查，超限返回 413
- 所有 `_read_body()` 调用点添加 `None` 返回值检查

**涉及文件**：`D:/loopcli/main/webui/server.py`

### HIGH-2: 未认证的 POST 端点

**问题**：仅 `/api/tasks` 和 `/api/messages/send` 在 `API_KEY` 非空时做认证，`/api/loopcli/dispatch` 等危险端点（可启动 `--dangerously-skip-permissions` 的 Claude 进程）在默认配置下无任何认证保护。

**修复**：
- 新增 `_require_auth()` 方法，使用 `hmac.compare_digest` 做时序安全比较（同时修复 LOW-1）
- 在 `_do_POST_impl()` 入口统一调用 `_require_auth()`，所有 POST 端点均受保护
- 移除 `_handle_loopcli_dispatch()` 中冗余的单独认证检查

**涉及文件**：`D:/loopcli/main/webui/server.py`

## 变更摘要

| 变更 | 说明 |
