## 实现内容
在 `D:/loopcli/run.py` 中添加了日志轮转功能：

1. **新增 `rotate_log()` 函数**（第 93-113 行）：
   - 检查 `raw.log` 文件大小，超过 1MB（1,000,000 字节）时触发轮转
   - 删除最老的归档 `raw.log.3`
   - 依次重命名 `raw.log.2 -> .3`、`raw.log.1 -> .2`
   - 将当前 `raw.log` 重命名为 `raw.log.1`
   - 最多保留 3 个归档文件

2. **在 `run_agent()` 中调用轮转**（第 312 行）：
   - 在每次打开 `raw.log` 写入之前调用 `rotate_log(log_file_path)`
   - 使用 append 模式打开，确保轮转期间不丢失日志

## 设计要点
- 纯标准库实现，无外部依赖
- 先重命名再打开，避免写入冲突
- 使用 `os.path.getsize()` 进行轻量级大小检查
- 异常安全：`getsize` 失败时静默跳过
