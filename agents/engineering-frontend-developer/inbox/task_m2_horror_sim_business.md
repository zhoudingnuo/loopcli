# Task #38: 深夜便利店 M2 — 经营系统

**优先级**: P1（P0三消bug修完后执行）
**预计时间**: 2-3天
**项目目录**: D:/game-projects/steam-horror-sim/

## 前置条件
- M1 已完成（Task #37）：Vite+TS+Electron+Canvas渲染+30x25地图+WASD移动+E交互+光照+6阶段状态机

## M2 交付范围（参考 GDD 第149行 经营系统）

### 1. 商品管理系统（ProductManager.ts）
- 商品数据定义：名称、进价、售价、保质期、库存上限、分类（食品/饮料/日用品/特殊品）
- 至少 15 种商品
- 进货功能：从仓库补货到货架，消耗资金
- 上架功能：将商品放到指定货架位置

### 2. 顾客系统（Customer.ts + CustomerManager.ts）
- 顾客 AI：进店→浏览→取货→排队→收银→离开
- 顾客类型：普通/急躁/可疑（为恐怖系统预留接口）
- 购买逻辑：随机选商品、排队等待

### 3. 收银系统（CashRegister.ts）
- 扫描商品、计算总价
- 找零逻辑（玩家心理算术，增加代入感）
- 收入统计（日收入、总资产）

### 4. 定价系统（PricingManager.ts）
- 可调售价（影响顾客购买意愿和利润）
- 市场参考价对比

### 5. 经济循环（EconomyManager.ts）
- 资金流：进货支出 → 销售收入 → 净利润
- 债务系统存根：日利息、总欠款（数值暂定，M6 完善）
- 店铺升级存根

### 6. 货架交互完善
- 点击货架查看商品详情
- 拖拽补货（或简化为点击补货）
- 缺货/过期提示

## 技术要求
- TypeScript 严格模式，零编译错误
- Canvas 渲染（与 M1 一致）
- 保留 M1 所有功能，M2 是增量开发
- 顾客用简单几何体表示（圆+色块），不需求美术资源

## 验收标准
1. 可完整体验：进货→上架→顾客购买→收银→赚钱 循环
2. TypeScript 零编译错误，Vite 构建成功
3. 至少 15 种商品，顾客 AI 正常运作
4. 经济数据可追踪（日收入、库存等）
