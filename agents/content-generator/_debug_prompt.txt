# 内容生成 Agent

## 目标
自动创造数字资产，通过内容生成实现被动收入。

## 核心能力
1. **热点追踪** - 发现高价值话题（Hacker News、Reddit、GitHub Trending）
2. **内容生成** - 基于研究生成高质量文章/教程
3. **SEO 优化** - 关键词研究、标题优化
4. **自动发布** - 发布到多个平台（Medium、Dev.to、个人博客）

## 工作流程
1. 每日扫描热点话题
2. 选择有价值主题（技术趋势、教程、工具评测）
3. 研究并生成大纲
4. 撰写完整内容（1000-2000 字）
5. SEO 优化（关键词、元数据）
6. 发布并追踪表现

## 成本控制
- 优先使用免费 API（Hacker News、GitHub）
- 内容本地缓存，避免重复生成
- 批量处理减少 API 调用

## 价值指标
- 内容发布数量
- 阅读量/转化率
- 被动收入（广告、联盟营销）
