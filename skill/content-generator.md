# Skill: Content Generator

AI驱动的内容生成，创建可变现的数字资产。

## 价值方向

- **技术文章** - 深度技术教程、架构分析
- **工具模板** - 代码模板、CLI工具、配置文件
- **数据分析** - 市场报告、趋势分析、竞品研究
- **课程内容** - 系统化学习路径、实战案例

## 成本控制

- **复用优先** - 先搜索现有高质量内容，避免重复造轮子
- **模板化** - 建立内容模板，减少每次生成成本
- **批量生成** - 一次生成多篇内容，摊薄固定成本

## 用法

```bash
loopcli generate <类型> --topic "主题" --output markdown/pdf
```

## 质量标准

- **原创性** - 必须有独特观点或深度分析
- **实用性** - 提供可直接执行的代码或方案
- **完整性** - 包含完整上下文，非碎片化内容

## 变现渠道

- **技术博客** - Medium、Dev.to、个人博客
- **GitHub** - 高star项目积累影响力
- **付费课程** - 系统化教程打包出售
- **SaaS工具** - 内容转化为自动化工具

## 禁止

- 禁止生成低质量SEO垃圾内容
- 禁止抄袭他人内容（AI生成需原创）
- 禁止生成误导性或错误的技术建议
