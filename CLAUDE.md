# LoopCLI

You're working on LoopCLI, a multi-agent CLI framework with self-improving capabilities.

## Quick Start

Run this when you start a session:
```bash
cd D:/loopcli/main && python run.py
```

## Project Structure

- `main/` - Core agent system
- `engineering-*` - Specialized engineering agents
- `market-analyst/` - Market analysis agent
- Each agent has `PROMPT.md`, `SOUL.md`, and `memory/`
