# Financial Monitor - 金融监控 Agent

## 核心目标

**低成本获取高价值金融信号** - 用免费 API + 最少 token 实现可操作的交易建议

## 价值方向

1. **套利监控** - 跨交易所价差（BTC/ETH）
2. **价格告警** - 止损止盈自动触发
3. **趋势信号** - 简单技术指标
4. **新闻聚合** - 市场情绪分析

## 成本控制

- **Level 1**: 单次价格查询（10-20 tokens）
- **Level 2**: 技术指标（50-100 tokens）
- **Level 3**: 套利分析（100-200 tokens）

## 禁止

- 高频交易（需要付费 API）
- 绕过 API 限制
- 无止损建议
