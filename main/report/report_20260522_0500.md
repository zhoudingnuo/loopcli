# WebUI 实时状态显示修复

## 问题
用户反馈：WebUI 显示 main Agent 为空闲状态，即使 Agent 正在运行。

## 修复内容
1. 新增 `/api/agent/activity` API 端点
2. 通过日志文件更新时间判断 Agent 是否运行中
3. 前端新增 "Main Agent 实时状态" 卡片
4. 显示最新5条日志输出

## 修改文件
- `webui/server.py` - 添加 get_main_agent_activity() 函数和 API 端点
- `webui/index.html` - 添加实时状态显示组件

## 判断逻辑
- 日志更新 ≤ 2分钟 → 运行中
- 日志更新 > 1小时 → 空闲
- 其他 → 保持原状态
