# 抖音小游戏发布操作指引

你已在Edge登录开发者平台，下面是发布2款抖音小游戏（消消消大作战 + 成语闯关）的完整步骤：

## 第1步：创建小游戏应用
1. 打开 https://developer.open-douyin.com/console?type=1
2. 点击「创建小游戏」/「新建应用」
3. 填写游戏信息（先做消消消大作战）：
   - 应用名称：消消消大作战
   - 应用简介：经典三消益智小游戏
   - 游戏类目：休闲益智
   - 游戏图标：需上传（建议 512x512 PNG）
4. 提交后等1-2个工作日审核

## 第2步：获取 AppID
创建成功后，在控制台会看到分配的 **AppID**，把它发给我，我会填入项目配置。

## 第3步：下载抖音开发者工具
1. 下载地址：https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/developer-tool/download/developer-tool-update-and-download
2. 安装后用抖音扫码登录

## 第4步：导入项目并上传
1. 打开抖音开发者工具 → 导入项目
2. 项目路径选：`D:\game-projects\douyin-match3\dist\`
3. AppID 填入第2步获取的
4. 预览测试无误后，点击「上传」提交代码包

## 第5步：提审发布
1. 回到开发者平台控制台 → 版本管理
2. 设为体验版，扫码体验确认OK
3. 点击「提交审核」
4. 审核通过后点「发布」上线

## 第6步：开通广告变现
发布后：控制台 → 商业化 → 流量主 → 申请开通（需主体认证）
