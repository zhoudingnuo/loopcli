# 抖音小游戏发布操作指南

你已登录开发者平台，按以下步骤操作：

## 第1步：创建小游戏应用
1. 在控制台点击「创建应用」或「新建小游戏」
2. 选择应用类型：**小游戏**
3. 填写游戏名称：`消消消大作战`
4. 游戏类目选：**休闲益智**
5. 提交创建

## 第2步：获取 AppID
创建成功后，进入该应用 → **开发管理 → 开发设置**，复制 **AppID** 发给我。

## 第3步：完善信息
- 上传游戏图标（正方形 512x512）
- 填写游戏简介
- 上传截图（至少3张）
- 添加隐私政策链接

## 第4步：告诉我 AppID
拿到 AppID 后发给我，我会：
- 自动填入项目配置
- 构建上传包
- 指导你上传提审

⚠️ 如果平台要求**主体认证**，先完成实名认证再创建应用。

先做第1步，有问题随时问我！
