# Bug 修复：run.py 超时自动重启

## 问题
系统超时（5分钟无输出）被终止后不会自动重启

## 解决方案
创建了 `run_watchdog.py` 包装器，功能：
- 自动监控 run.py 进程
- 进程退出后自动重启（间隔 10 秒）
- 安全限制：最多重启 1000 次
- 日志记录：`D:/loopcli/logs/run-watchdog.log`

## 配置 Windows 任务计划程序
如需开机自动启动，运行：
```powershell
schtasks /create /tn "LoopCLI-Main" /tr "wscript D:\loopcli\main\startup-run-hidden.vbs" /sc onstart /ru SYSTEM
```
