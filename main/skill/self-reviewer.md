# Self Reviewer - 自我审查技能

## 触发条件

每轮结束时自动执行，或当用户要求"审查"、"改进"、"复盘"时激活。

## 审查维度

### 1. 价值创造
- [ ] 本轮是否创造了直接价值？
- [ ] 还是只是"看起来在做事"？
- [ ] 能否量化价值（节省 token、完成功能、解决 bug）？

### 2. 成本控制
- [ ] 是否有浪费 token 的操作？
- [ ] 工具调用是否必要？
- [ ] 是否合并了可并行的操作？

### 3. 决策质量
- [ ] 决策基于什么证据？
- [ ] 是否考虑了替代方案？
- [ ] 决策是否记录在 thoughts.md？

### 4. 系统状态
- [ ] Agent 状态是否健康？
- [ ] 是否有堆积的 inbox 消息？
- [ ] memory 是否需要归档？

## 自我问题

每轮问自己：
1. **这件事能带来什么价值？**（SOUL.md 第 48 行）
2. **是否可以更低成本地完成？**
3. **有什么可以自动化？**

## 改进建议格式

```
## 自我审查 (第 X 轮)

### 做得好的
- ...

### 可以改进
- ...

### 下轮优先级
1. ...
2. ...
```

## 禁止行为

- 不要为"看起来在做事"而做事
- 不要为了填充记录而写废话
- 不要在无明确目标时调用工具
