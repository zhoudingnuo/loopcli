# LoopCLI WebUI v3 使用指南

## 版本信息
- **当前版本**: v3.1
- **更新日期**: 2026-05-22
- **文件大小**: 2510 行

## 功能概览

### 1. 主题切换
- **快捷键**: `Ctrl + T` (Mac: `Cmd + T`)
- **功能**: 在深色和浅色主题之间切换
- **持久化**: 主题选择会保存在浏览器本地存储中

### 2. 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `1-6` | 切换到对应页面（仪表盘、Agent列表、任务管理、实时日志、控制面板、发送消息） |
| `N` | 打开新建任务模态框 |
| `Ctrl + B` | 折叠/展开侧边栏 |
| `F11` | 全屏模式 |
| `Ctrl + M` | 紧凑模式 |
| `Ctrl + T` | 切换主题 |
| `Esc` | 关闭模态框 |

### 3. 活动趋势图表
- **位置**: 仪表盘页面
- **功能**: 实时显示 Agent 运行状态变化
- **特性**:
  - 渐变填充效果
  - 数据点悬停提示
  - 网格线辅助
  - 30 秒自动更新

### 4. 快捷操作面板
- **位置**: 仪表盘页面
- **功能**: 一键访问常用功能
- **包含**:
  - 新建任务
  - 控制面板
  - 查看日志
  - 切换主题

### 5. 性能监控
- **位置**: 仪表盘页面
- **显示指标**:
  - WebUI 版本
  - 页面加载时间
  - 数据刷新间隔
  - 运行时间（实时更新）

### 6. 移动端支持
- **自适应布局**: 支持桌面、平板、手机
- **侧边栏**: 移动端自动隐藏，点击按钮滑出
- **遮罩层**: 点击遮罩关闭侧边栏

## 页面说明

### 仪表盘
- 系统统计卡片（Agent 总数、运行中、空闲、待处理任务、Token 用量、预估成本）
- 快捷操作面板
- 活动趋势图表
- Main Agent 实时状态
- 性能指标
- Agent 概览

### Agent 列表
- 显示所有 Agent 的详细信息
- 展开/收起任务列表
- 实时状态更新
- 数据导出（CSV/JSON）

### 任务管理
- 按Agent筛选任务
- 任务状态显示
- 创建新任务
- 数据导出（CSV/JSON）

### 实时日志
- SSE 实时日志流
- 按Agent筛选
- 关键词搜索
- 暂停/继续
- 清空显示
- 自动滚动
- 数据导出（CSV/JSON）

### 控制面板
- Loop 进程控制（启动/停止/重启）
- 进程状态监控（PID、运行时长、迭代次数、启动时间）
- 一键派发任务

### 发送消息
- 向指定 Agent 发送消息
- 消息历史记录

## 技术特性

### 响应式设计
- 桌面端: 侧边栏可折叠
- 移动端: 侧边栏滑出式

### 性能优化
- 页面加载时间监控
- 10 秒自动刷新数据
- 高效的 DOM 更新

### 浏览器兼容性
- Chrome/Edge: 完全支持
- Firefox: 完全支持
- Safari: 完全支持
- 移动浏览器: 完全支持

## 支持
如遇问题，请检查：
1. 浏览器是否为最新版本
2. JavaScript 是否已启用
3. 网络连接是否正常
4. 后端服务是否运行（端口 8080）
